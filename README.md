# Django Webscraper

A simple Django-based web application that scrapes all anchor tags (links) from a user-specified URL, stores them in a database, and displays them in a clean, user-friendly interface.

## 🚀 Project Description

This Django Webscraper allows users to:
- Input a URL.
- Scrape all anchor (`<a>`) tags from the webpage.
- Store the links (text and href) in a database.
- View the scraped links in a structured table.
- Clear all stored links with a single click.

## 🛠 Features

- 🔍 **Web Scraping**: Enter any URL and extract all the anchor links from the page.
- 🗂 **Data Display**: View scraped link text and URLs in a Bootstrap-styled table.
- 🗑 **Clear Links**: Easily delete all stored links with a single click.
- 🎨 **User Interface**: Clean and responsive UI using Bootstrap.
